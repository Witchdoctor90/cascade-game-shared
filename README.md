# cascade-game-shared

Публічні сторінки застосунків: лендинг Cascade та спільні блоки.

```
index.html          лендинг Cascade
assets/             стилі, скрипти, шрифти (Inter, JetBrains Mono, ліцензії OFL поруч), зображення
shared/             блоки, спільні для лендингів усіх застосунків (див. shared/README.md)
```

Це статичний сайт без збірки. Локально:

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## Публікація

*Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`.* Адреса: `https://witchdoctor90.github.io/cascade-game-shared/`. Усі шляхи відносні, тож сайт працює і з підкаталогу, і з власним доменом. Якщо адреса інша, поправте `og:image` в `index.html`: для превʼю в соцмережах потрібен абсолютний URL.

## Що всередині

- **Демо гри** (`assets/js/cascade.js`): палітри, скіни блоків, очки й комбо-віхи взято з застосунку. Поки ніхто не торкається поля, грає бот; клік, торкання, стрілки й пробіл переймають керування.
- **Повзунок комбо**: блок номер N за хід дає 10 × N очок, рівні банерів збігаються з грою.
- **Теми та скіни**: перемикають усю сторінку й гру нагорі; вибір, мова й тема зберігаються в `localStorage`.
- **Мови**: українська й англійська, за замовчуванням з мови браузера. Тексти в `assets/js/site.js`, статична українська версія є в `index.html` (для пошуковиків і для запуску без JS).
- **`<play-badge>`**: плашка «Скоро в Google Play» зі `shared/`. Коли застосунок вийде, додайте їй `live` і `href` (див. `shared/README.md`).

Сторінка поважає `prefers-reduced-motion`: бот і анімації вимикаються, гра чекає на вас.

## Новий застосунок

Створіть `notes/index.html`, підключіть `../shared/play-badge.js` і задайте плашці власну тему через CSS-змінні `--pb-*`. Структура, текст і поведінка плашки лишаться тими самими.
